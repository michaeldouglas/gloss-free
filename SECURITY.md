# Segurança e dados sensíveis

Este projeto não deve conter tokens, senhas, arquivos `.env`, vídeos brutos
nem outros dados pessoais ou restritos.

Se encontrar uma vulnerabilidade no código ou um segredo exposto, não abra uma
issue pública com os detalhes. Use o recurso privado de reporte de segurança
do GitHub ou entre em contato privado com os mantenedores do repositório.

Ao relatar um problema, informe a localização afetada, o impacto observado e,
quando possível, uma forma segura de reproduzi-lo. Não envie dados pessoais ou
vídeos de participantes no relato.
